# Fuente local del título

Ritual Headline es un subconjunto latino en WOFF2 derivado de Archivo Black (Google Fonts), renombrado para esta entrega. Conserva los contornos originales y se distribuye bajo SIL OFL; ver OFL.txt.

Origen: https://github.com/google/fonts/tree/main/ofl/archivoblack

Solo se aplica a TECH BAR CULTURAL. Se mantienen los tamaños, espaciado, peso CSS y composición aprobados. Comparación en el mismo viewport desktop: título anterior 634,40625 px; fuente local 634,421875 px. La fuente se precarga y se sirve desde la propia carpeta, sin CDN ni dependencia de fuentes instaladas.
